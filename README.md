# The Dialogue Co.

Static website for The Dialogue Co., hosted on GitHub Pages.

Edit `index.html` (content) and `styles.css` (look). No build step.

## 3D hero

The interactive header lives in `src/hero3d.js` (three.js). After editing it, run:

    npm install
    npm run build

This writes the bundled `hero3d.js` that the page loads. Commit both.
